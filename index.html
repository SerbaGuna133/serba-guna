📖 Panduan Setup Firebase & GitHub Pages

🔥 1. Cara Menghubungkan ke Firebase (Cloud Database)

  1. Buka Firebase Console login dengan email toko Anda.
  2. Klik Add Project, beri nama misalnya: tb-serbaguna-finance.
  3. Pilih menu Firestore Database > Klik Create Database (Pilih mode Start in test mode).
  4. Masuk ke Project Settings (Ikon Gir) > Bagian Your apps > Pilih ikon Web (</>).
  5. Salin kode konfigurasi (apiKey, projectId, authDomain, appId).
  6. Tempelkan ke menu Pengaturan > Integrasi Firebase di aplikasi ini, lalu klik Hubungkan!

🚀 2. Cara Publish Gratis ke GitHub Pages

  1. Buka GitHub login dengan akun GitHub email toko Anda.
  2. Buat repositori baru bernama serba-guna (Pilih Public).
  3. Upload semua file di dalam folder Serba-Guna ini ke repositori tersebut.
  4. Buka menu Settings di repository GitHub > Menu Pages.
  5. Pada bagian Branch, pilih main lalu klik Save.
  6. Website pembukuan toko bangunan Anda langsung online di: https://username-toko.github.io/serba-guna/!
